# AIA UGOT Design Portfolio (Criteria A-D landing + 13 Criterion B lessons)

1. Upload EVERYTHING in this folder to your GitHub repo root (replace the old files), Settings -> Pages -> main / root.
2. Open `assets/config.js` and paste your Google Apps Script /exec URL between the quotes (one place, whole site).
   Apps Script steps are in `google-apps-script/Code.gs` (unchanged: your existing deployment keeps working).
3. Criteria A, C and D are placeholder pages until you add the rubrics/samples.

Pages: index.html (landing), criteria-a/b/c/d.html, lessons/topic-NN.html (02-10, 12-15).
Sensor ranges and the kit mount are design targets: verify against the UGOT datasheet.
